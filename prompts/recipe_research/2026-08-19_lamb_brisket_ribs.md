## 1. 香煎羊小排

**来源**
- https://www.myforkinglife.com/pan-seared-lamb-chops/
- https://girlcarnivore.com/pan-seared-lamb-shoulder-chops/
- https://simmerandsauce.com/recipes/pan-seared-lamb-chops/

**提炼出的生产事实**

| 事实 | 值 |
| --- | --- |
| 预处理 | 厨房纸吸干，两面撒粗盐和现磨黑胡椒，室温静置约 20 分钟 |
| 煎 | 厚底铁锅中高火，橄榄油热到冒油纹，单层下锅，**不要动，煎 3-4 分钟**至深褐 |
| 加料时机 | **转中火之后**才下黄油、蒜、迷迭香、**百里香** |
| 浇淋 | 锅倾斜，用勺把冒泡的香草黄油反复浇在肉上，1-2 分钟 |
| 熟度 | 中等 135-145°F，目标 **140°F** |
| 静置 | **5 分钟**，余温再升 3-5°F，肉汁回流 |

**我原来写错的**
- 写成"先立起来煎脂边" → 实际是**平放煎**
- 漏了**百里香**
- 没写静置

**转成可见状态**
- 生：深玫瑰红、哑光致密，脂肪盖硬实乳白，骨柄干净
- 煎中：贴锅面深金褐硬壳，侧面仍生红 —— 变化正在发生
- 浇淋：黄油起泡呈淡金，勺流打在壳上
- 成品断面：**通体玫瑰粉、不透明、肉汁清澈**。不是暗红生肉，不是灰色过熟

## 2. 红烧牛胸肉

**来源**
- https://m.xiachufang.com/recipe/107609317/ （红烧牛胸骨）
- https://home.meishichina.com/recipe-12378.html （红烧牛肉）
- https://m.xiachufang.com/recipe/106540916/ （红烧牛肉不用高压锅）

**提炼出的生产事实**

| 事实 | 值 |
| --- | --- |
| 预处理 | 清水浸泡 30-60 分钟去血水 |
| 焯水 | 冷水下锅，加**花雕酒、葱段、姜、花椒** |
| 炒香 | **葱、姜、八角、桂皮** 下油锅炒出香味 |
| 调味 | **生抽 3 勺、老抽 2 勺、冰糖 4-5 颗** |
| 加水 | **开水**没过牛肉 |
| 时长 | 砂锅约 **2 小时**（1 小时后调盐，再 1 小时） |

**我原来写错的（这条错得最离谱）**
- 我写"两把叉子把肉撕开、肉丝散开" —— 那是**美式 BBQ pulled beef** 的手势。
  红烧牛肉是**切块上桌**，成品是方块状带光泽的深红棕，不是撕碎的肉丝。
- 我把它想成西式 braise，实际是**深色酱油底 + 冰糖上色**，成品是红亮的。

**转成可见状态**
- 生：整块牛胸肉，脂肪层与瘦肉分明
- 焯水后：表面转灰白、浮沫撇净
- 炖中：深红棕汤汁在**微微冒泡不翻滚**，肉块半没在汤里，油光在表面
- 成品：**深红棕、发亮、切块**，筷子能夹开但保持块形。**不能写 pale，要写不透明的
  深棕，纤维分明**

**冰糖是这道菜上色的关键**，画面里那层红亮的光泽来自它，不是来自番茄或辣椒。

## 3. 蜜汁烤猪肋排

**来源**
- https://m.xiachufang.com/recipe/105947284/ （蜜汁烤猪排）
- https://lanfanapp.com/recipe/3224 （蜜汁烤排骨）
- https://maggiehome.pixnet.net/blog/post/209765863- （蜜汁烤豬肋排）

**提炼出的生产事实**

| 事实 | 值 |
| --- | --- |
| 腌料 | **蜂蜜、蒜、洋葱、料酒、生抽、蚝油、玉米淀粉、百里香** |
| 预处理 | 吸干水分，**用叉子或牙签在肉上戳洞**帮助入味 |
| 腌制 | 装袋**冷藏一夜** |
| 第一段烤 | **锡纸包好**，230°C 上下火 **30 分钟** |
| 刷酱 | 剩余腌汁加玉米淀粉和两勺蜂蜜调匀 |
| 第二段烤 | 拆锡纸，刷一遍 200°C 5 分钟，翻面再刷再烤 5 分钟，**重复到表面上色微脆** |

**我原来写错的**
- 我写成"刷一次酱进烤箱" → 实际是**锡纸包烤 30 分钟在先**，之后才是**反复刷酱-回烤**
  的循环。那个"一层层上釉"的高级感正是来自反复刷，不是一次刷。

**转成可见状态**
- 生：三条带皮肋排，肥瘦相间层次分明
- 腌后：表面裹一层深色腌汁，戳孔可见
- 刷釉中：**深红棕、发亮、边缘起泡**，一层压一层。不是黑，不是焦
- 成品：骨间切开，提起一根，肉与骨分离但不散

## 两款饮料

**BOSS Café au Lait** 和 **茉 小奶茉牛乳茶** 是即饮商品，没有"菜谱"。产品事实来自
包装本身：

- BOSS：SUNTORY，185g 罐，**北海道生クリーム & 厳選牛乳**，コーヒー飲料。
  成品色是**暖焦糖米色、不透明**（它就是奶咖，允许是咖啡色）
- 茉：350ml PET，鼠尾草绿标，**低糖低脂**、**真奶真茶 0奶糖**，茉莉叶标记。
  成品色是**浅奶茶米色**

**注意**：茉这条和 2026-08-19 上午做的栀栀乌龙奶茶颜色几乎一样，两条会撞。
场景必须从一开始就分开：乌龙走桦木+绿植的茶室调，茉走**亚麻+晨光+饼干**的下午茶调。
