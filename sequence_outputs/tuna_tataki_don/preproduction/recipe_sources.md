# Recipe Sources

Dish: Tuna Tataki Don

Target: Australia / Instagram Reels / MiniMax H3 3 x 5s Ref2VA.

Primary source:

- Just One Cookbook, "Tuna Tataki": https://www.justonecookbook.com/tuna-tataki/

Useful recipe logic:

- Use sashimi-grade yellowfin/ahi tuna.
- Quickly sear the outside, keeping the centre rare.
- Ginger ponzu sauce: green onion, grated ginger, ponzu, toasted sesame oil, soy sauce, toasted sesame seeds.
- Slice thinly after searing.

Commercial adaptation:

- Make it a rice bowl for stronger IG payoff: sushi rice, seared rare tuna slices, cucumber/avocado, nori, scallion, sesame, ginger ponzu drizzle.
- The supplied tuna image is used for colour and freshness identity, but the generated prep reference should show a tuna loin/block so the tataki sear action is readable.
